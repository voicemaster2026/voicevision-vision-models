# VoiceVision VisionFusion model bundle

This repository contains the complete source, deterministic synthetic-data
trainer, evaluation artifacts, dataset manifest, and PyTorch weights for
VisionFusion `0.1.0`.

## Model and limits

VisionFusion combines a 64×64 RGB scene, a vector-drawn region mask, and a Czech
or English text transcript. It predicts a bounded task proposal, a synthetic
shape class, and a synthetic color class. Its training and evaluation samples
are generated by the included script; there are no camera images, audio,
customer data, or real-part examples. The recorded 100% held-out accuracy is
only for the generated evaluation set. It does not establish industrial
inspection quality, real-scene understanding, defect localization, calibrated
confidence, or production readiness. Do not use it to accept or reject parts.

The included weight file is the exact VisionFusion `0.1.0` checkpoint:

```text
SHA-256  a132cbc2b933a82774ab728891ade5723e4967fe78f175b97bc319433ff3550f
Size     319,726 bytes
```

`models/vision-fusion/0.1.0/artifact.json` records the model architecture,
training settings, source hashes, dataset-manifest hash, and limitations.
`evaluation.json` records held-out metrics and ablation results.

## Use over SSH

```sh
git clone git@github.com:voicemaster2026/voicevision-vision-models.git
cd voicevision-vision-models
python -m venv .venv
. .venv/bin/activate
pip install -r requirements-inference.txt
```

The public GitHub repository can be read by anyone. SSH cloning requires a
GitHub account with an SSH key; HTTPS cloning is also available.

Inference is exposed by `voicevisionunited.vision_fusion.propose`. The model
expects an image path, vector strokes, and a text transcript; see the API and
input limits in [the model card](models/vision-fusion/0.1.0/README.md).

## Reproduce training

```sh
pip install -r requirements-training.txt
python tools/train_vision_fusion.py --output models/vision-fusion/reproduction
```

The trainer uses fixed seeds and separately generated train/evaluation sets.
It refuses to overwrite a nonempty output directory. The checked-in
`0.1.0` artifact is preserved; a reproduction run does not replace it.
